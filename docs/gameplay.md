# ゲーム仕様

[READMEに戻る](../README.md)

## コンセプトとラン

プレイヤーはプログラミング言語となり、敵として現れる処理要求（タスク）を実行します。コード入力は行わず、型付け・言語機能・基盤強化で戦闘スタイルを組み立てます。

1. WASD・HJKL・矢印キーで移動する。斜め移動も同じ速度。
2. 射程内の最も近いタスクを自動攻撃する。
3. 処理後の ◆（経験値）を回収し、レベルアップで能力を選ぶ。
4. メモリが0になるとラン終了。5分間生存するとクリア。

## 型付けと途中の設計強化

起動前に1 / 2でStatic Typing／Dynamic Typingを選び、Enterで起動します。型付けはFeature／Infraの採用枠を使いません。

| 方針 | 基本効果 | 見え方 |
| --- | --- | --- |
| Static Typing | 射程内の未被弾タスクを毎秒2体まで事前検査。検査済みへの初撃を50%強化 | 金色の枠とチェック印。初撃で印を消費 |
| Dynamic Typing | 初命中でタスクを検査。そのタスクへの後続ダメージを30%強化 | 命中後に青い枠と菱形の印。処理完了まで維持 |

型付けのダメージ補正は通常弾・オブジェクト弾・連鎖・範囲攻撃・貫通弾を共通の命中処理で扱います。連鎖の元威力に補正を持ち越さず、各命中先で判定します。静的型付けは敵の予告時間や基本威力を変更しません。動的型付けは対象切り替えや敵種切り替えを発動条件にしません。

レベル5・10・15で、通常の能力選択に先立つ**追加の2択**があります。

- **検査範囲**：Staticは毎回の検査対象+2体。Dynamicは初回の検査を周囲100以内の未検査タスクへ伝播する数+1体。
- **検査効果**：型付けによるダメージ加算+15ポイント。

選択後に、そのレベルの通常のFeature／Infra選択も行います。設計強化は追加枠で、通常の成長を消費しません。型付けは最大Lv.4。サイドバーに現在の設計効果とレベルを表示します。

## Feature

Featureは最大4種類、各4ランク。初回取得で基本威力・最大メモリ・索敵範囲を減らす制約は撤廃しました。それぞれ独立した攻撃、または通常攻撃を直接強化する効果を持ちます。制約は主に射程・対象数・起動条件・準備時間です。

以下の数値は調整用の基礎値です。ゲーム内の説明文は挙動と使いどころを中心にし、数値は選択カードの効果欄へまとめます。

| Feature | 攻撃と成長 | 得意な場面・制約 |
| --- | --- | --- |
| Garbage Collection | 周囲への範囲攻撃。基礎間隔3秒、威力36→78、半径133→187 | 群れ・正面装甲。攻撃の合間がある |
| Concurrency | 通常攻撃の異なる対象+1 / ランク。単発威力の低下なし | 散った敵。単体への発射数は増えない |
| OOP | 自律オブジェクト+1 / ランク。威力20→32、基礎間隔0.9秒 | 独立攻撃・側背面。対象は各オブジェクトが選ぶ |
| Functional Programming | 通常弾の連鎖+1 / ランク。次の対象への威力70%、連鎖射程155 | 密集したタスク。同じ連鎖は同じ敵を再処理しない |
| Null Safety | 周囲への攻撃。威力28→58、基礎間隔1.8秒。Null参照へ1.5倍。範囲内のNull弾も消去 | 再充填する防壁でNull弾・Null参照の接触を1回防ぐ。普通の弾・接触・爆発は防げない |
| ベクトル化 / Vectorization | 直線貫通弾。威力42→78、幅12→24、基礎間隔2.8秒 | 一列の群れ・奥の敵。発射後の追尾なし |
| Lazy Evaluation | 足元に待機する設置攻撃。0.35秒後に起動可能となり、敵が半径の65%以内へ近づくと範囲攻撃。その後1.5秒減速 | 威力46→94、半径105→150、減速30→45%。基礎設置間隔4秒、未起動寿命7秒、最大3個。エリートの減速は最大20% |
| Memoization | 独立した処理弾。基礎間隔1.5秒、初回入力の威力30→66。処理済み入力は威力1.8倍・弾速1.5倍のキャッシュ弾で優先処理 | 同じ操作・入力の繰り返し。入力は姿と足元の点の数で識別。保存はラン内のみ |
| JIT Compilation | 取得後の通常攻撃8回で解析完了。通常攻撃速度+40→85%。対象変更・待機でリセットしない | 持続的な戦闘。金色の解析ゲージと「解析中／最適化済み」、最適化後の金色弾で表示 |
| Ownership | 近距離への範囲攻撃。威力32→68、半径105、基礎間隔1.6秒。近距離の撃破で2→5回復 | 回復予算6→12 / 秒は全攻撃で共有。召喚雑魚からは回復しない |

ベクトル化は旧Pattern Matchingの貫通挙動を継承します。既存の図鑑発見記録を保つため、内部IDとアイコンのパスは `patternMatching` のままです。

メモ化の入力キーは「敵種＋入力バリエーション」です。取得後の撃破で結果を保存し、同じキーの別タスクへ再利用します。初めての入力でも攻撃するため、他のFeatureを必要としません。キャッシュ弾は再攻撃の予約や再帰的な攻撃生成を行いません。

JITは対象別の威力蓄積を廃止しました。複数対象への同時攻撃も通常攻撃1回と数え、OOP・連鎖・メモ化から解析を二重に進めません。最適化はラン終了まで維持します。

## Infra

Infraは8種類から最大4種類、**すべて最大6ランク**です。上限後は候補から外れます。

| Infra | 効果 / ランク | 対象・前提 |
| --- | --- | --- |
| Memory Expansion | 最大メモリ+25、取得時に現在メモリ+35 | 新しい最大値で回復を制限 |
| Clock Speed | 基本移動速度に+8% | 移動だけを強化 |
| Cache Locality | 経験値回収半径+22、通常攻撃射程+12 | 入力結果を保存するメモ化とは別 |
| Compiler Optimization | 通常攻撃とFeatureの攻撃間隔×0.92 | 通常・OOP・GC・Null・貫通・設置・メモ化・Ownership。防壁再充填や無敵時間は対象外 |
| Transfer Bandwidth | プレイヤー弾速×1.15 | 追尾弾・貫通弾。上限1600、キャッシュ弾の高速化にも上限を適用 |
| Spatial Index | 基本範囲に+10% | GCと新しい設置攻撃。いずれかの取得後に出現 |
| Coprocessor | OOP攻撃間隔×0.92 | OOP取得後に出現。コンパイラ最適化と乗算 |
| Memory Protection | 被弾後の無敵時間+0.08秒 | 最初の被弾そのものは防がない |

コンパイラ最適化の役割を威力上昇から攻撃間隔短縮へ変更し、命令パイプラインを統合しました。旧 `pipeline` IDは記録の互換性のため保持しますが、抽選・図鑑には登場しません。

## 能力抽選と画面

- 能力選択・一時停止中は戦闘とすべてのタイマーが停止する。
- 取得済み能力の強化は採用枠を使わない。枠が埋まると、そのカテゴリの未取得能力を除外する。
- 候補が3種類以上あれば重複しない3択。両カテゴリに候補があればFeatureとInfraを各1つ以上含む。レベル5以降は取得済みFeatureを重み付けする。
- 候補が1〜2種類ならその枚数。すべての強化完了後はレベルアップでメモリを35回復する。型付けの節目では追加の設計選択を行う。
- **1 / 2 / 3、Tab → Enter、クリック**で取得。型付け強化は1 / 2を使用する。
- ゲーム描画領域内にカードを重ね、通常HUDのメモリ・時間・経験値と、サイドバーのビルドを保持する。
- 説明・数値・使いどころは常時表示。ホバーによる比較操作は不要。
- 新しい能力値は値だけ、既存値の変化は矢印で表示。変化しない数値行は重複表示しない。
- メモリ増設は現在値／最大値と回復後を比較する。
- Featureは暖色、Infraは緑。カードの角丸は共通、専用アイコンをカード・ビルド・図鑑で共有する。

## 敵とラッシュ

| 敵 | 初登場 | 行動・対処 |
| --- | --- | --- |
| リクエスト | 開始時 | 基本の追跡型。接触9 |
| 割り込み | 20秒 | 高速追跡。接触9 |
| 重複リクエスト | 30秒 | 同じ入力のペアで出現。メモ化は一方の結果を後続へ再利用できる |
| RPC要求 | 40秒 | 発光と構えの後、固定方向に弾を撃つ。準備0.65秒、弾速180、ダメージ11 |
| メモリ確保 | 45秒 | 遅い高耐久。通常の3倍の耐久、接触15 |
| Null参照 | 65秒 | Null弾を放つ。Null Safetyが追加ダメージ・弾消去・被弾防止で有効 |
| Buffer Overflow | 70秒 | 撃破位置に爆発を予告。1.1秒後、半径75、ダメージ18。円から離れる |
| デッドロック | 75・165・255秒 | エリート。方向を0.9秒予告して0.7秒突進。接触22。横へ避ける |
| Fork Bomb | 110秒 | 1.2秒の準備後に小型タスクを3体召喚。本体を優先処理する |
| Scheduler | 140秒 | 半径150の味方の移動を25%、攻撃準備を15%加速。支援は重複しない |
| 装甲メモリ確保 | 160秒 | 正面の弾ダメージを45%軽減。側背面と範囲攻撃は軽減しない |

通常射撃とNull弾の長い予告線は表示しません。発射前の発光と顔の変化、読みやすい弾を使用します。突進の方向予告と爆発範囲は維持します。

45秒ごとに9秒間のラッシュがあり、追跡型・高速型がまとまって出現します。平常時の出現も時間とともに増加。敵は最大240体、通常出現は236体まででエリート用の余地を残します。

特殊な敵は出現コスト18を共有し、種類ごとの上限もあります。初登場が来た役割は再出現より優先し、まだ登場していない各役割の最初の編成分を予約します。初回編成のコスト合計も18以内に調整し、早い時間帯の射撃型で予算が埋まって後半の種類が出なくなることを防ぎます。重複リクエストのペアも予算と上限に含めます。

召喚雑魚は本体ごとに最大6体、経験値1。本体を倒すと追加召喚が止まります。敵弾最大96発、貫通弾最大12発、追尾弾最大384発、設置攻撃最大3個、予告爆発最大24個です。

相性は密集・軌道・距離・継続処理・同じ入力・Null参照によって生まれます。Null Safetyには明示的なNull特効がありますが、特定Featureがないと倒せない敵や完全耐性はありません。

## 図鑑・保存・音声

ランタイム図鑑は画面下に常時表示し、遭遇した敵・取得した能力を記録します。未発見項目は `???`。記録は次のランにも引き継ぎます。

敵の表は**名前・挙動・相性の良い言語機能**。重複する「種類」の列は廃止しました。能力の表は名前・特徴・性質と制約です。説明では細かい秒数・半径・ダメージを繰り返さず、攻撃の特徴と対処を伝えます。

- Esc / Pで停止・再開。タブが非アクティブになった場合も自動停止。
- 設定を閉じた後は再開操作が必要。日英切り替えは進行を保持。
- 言語・音量・ミュート・発見記録をブラウザに保存。途中保存・ビルド共有は未対応。
- 初期音量100%。戦闘中はオリジナルBGM「Runtime Loop」。選択・停止・設定・終了ではBGMを止め、再開時は続きから再生。

## 終了時の言語プロフィール

勝敗にかかわらず、型付けとFeatureの投資量から言語傾向を表示します。戦闘のダメージ計算と独立しています。

- Static：GC＋ConcurrencyでGo、GC＋OOPでJava、OOP＋関数型でScala、Ownership重視でRust寄り。
- Dynamic：関数型＋ConcurrencyでJavaScript、OOP重視でRuby、GC主体でPython寄り。
- 投資が少ない、または該当しない構成は「独自設計の言語」。主に伸ばした機能も表示。

分類はゲーム内の設計傾向であり、実際の言語との一致を意味しません。能力の表現も概念を戦闘へ置き換えたもので、現実の言語間の性能差を示しません。

## 次のプレイで見る点

数値は仮調整です。自動テストの5分間シミュレーションではメモリを補充しており、勝率や実際の難易度を保証するものではありません。

- 最初のFeatureをどれにしても、攻撃が増えたと感じられるか。
- Staticの初撃とDynamicの後続強化を、印と戦闘から区別できるか。
- JITの解析完了と、メモ化の入力再利用が伝わるか。
- 群れ・単体・射撃・Null参照で、有効な位置取りや能力が変わるか。
- コンパイラ最適化や最大ランクで、特定の攻撃だけが突出しないか。
