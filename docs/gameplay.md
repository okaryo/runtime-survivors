# ゲーム仕様

[READMEに戻る](../README.md)

## コンセプトとラン

プレイヤーはプログラミング言語となり、敵として現れる処理要求（タスク）を実行します。コード入力は行わず、言語機能と基盤強化の選択で戦闘スタイルを組み立てます。

1. WASD・HJKL・矢印キーで移動する。斜め移動も同じ速度。
2. 攻撃範囲内の最も近いタスクを自動攻撃する。
3. 倒したタスクが落とす ◆（経験値）に近づき、回収する。
4. レベルアップすると戦闘と時間が停止し、3択から能力を取得する。
5. メモリが0になるとラン終了。5分間生存するとクリア。

ランの途中保存やビルドの外部共有はありません。終了画面で獲得能力を確認し、最初から遊び直せます。

## 能力

**言語機能（Feature）** は攻撃方法や挙動を変え、**基盤強化（Infra）** は基本性能を上げます。

| 区分 | 能力 | 効果（ランクごと） | トレードオフ |
| --- | --- | --- | --- |
| Feature | Garbage Collection | 3秒ごとの範囲攻撃。範囲・威力も増加 | 通常攻撃の間隔 +0.08秒 |
| Feature | Concurrency | 通常攻撃の対象 +1 | 通常攻撃の単発威力 ×0.88 |
| Feature | OOP | 自律オブジェクト +1体。威力も増加 | 最大メモリ −5 |
| Feature | Functional Programming | 通常攻撃の連鎖 +1回 | 通常攻撃の索敵範囲 −15 |
| Infra | Memory Expansion | 最大メモリ +25、現在メモリ +35（上限まで） | なし |
| Infra | Clock Speed | 移動速度 ×1.12 | なし |
| Infra | Cache Locality | 経験値回収範囲 +35、索敵範囲 +20 | なし |
| Infra | Compiler Optimization | 通常攻撃の威力 ×1.25 | なし |

4種類のFeatureはすべて共存でき、各4ランクまで取得できます。採用する機能数に別の上限はありません。Infraは繰り返し取得できます。最大ランクのFeatureは3択に出現しません。強化可能なFeatureがある間は、FeatureとInfraを各1つ以上含む3択になります。

- OOPのオブジェクトは0.9秒ごとに独立して近くのタスクを攻撃します。
- 関数型の連鎖は通常攻撃から発生し、連鎖ごとに威力が70%になります。同じ連鎖内で同じタスクを再度攻撃しません。
- コンパイラ最適化は通常攻撃と、その通常攻撃から生じる連鎖に効果があります。

### 能力の選択と表示

3枚のカードをゲーム描画エリア内に重ね、上部のHUDと通常のサイドバーを保ちます。PC画面で、説明と効果をスクロールなしで読める構成です。

- **1 / 2 / 3**、**Tab → Enter**、またはクリックで取得する。
- カードの説明と数値は常時表示する。ホバーによる比較操作は不要。
- 新しく追加する能力の数値は `36` のように追加後の値だけを表示する。
- 既存のステータスや取得済み能力の変化は `36 → 50` のように表示する。
- メモリ増設では、現在メモリと最大メモリを `35/100 → 70/125` のように表示する。
- 数値は実際の戦闘・取得処理と同じ計算を使い、回復上限やデメリットも反映する。
- トレードオフは該当する数値行の色で示す。

Featureは暖色、Infraは緑系で区別します。カードの角丸は共通です。能力ごとの専用アイコンをカード・サイドバー・図鑑で共通利用します。

## 敵とラッシュ

| 敵 | 種類 | 登場時期 | 特性 | 接触ダメージ |
| --- | --- | --- | --- | --- |
| リクエスト | 通常タスク | 開始時から | 基本の追跡型 | 9 |
| 割り込み | 高速タスク | 20秒以降 | 小さくすばしっこい | 9 |
| メモリ確保 | 高耐久タスク | 45秒以降 | 移動は遅く、耐久力は通常の3倍 | 15 |
| デッドロック | エリートタスク | 75・165・255秒 | 方向を予告してから突進する | 22 |

デッドロックは0.9秒間の予告後に0.7秒間突進します。予告方向は固定されるため、横へ避けられます。

45秒ごとに9秒間のラッシュが発生し、まとまった数の敵が出現するとともに通常スポーンも加速します。平常時の出現頻度も時間とともに上がります。敵の同時数には上限があります。

## 一時停止・言語・保存

- Esc / Pで一時停止・再開する。タブが非アクティブになった場合も自動停止する。
- 能力選択・設定・図鑑を開いている間は、戦闘と時間を停止する。
- 戦闘中に開いた設定・図鑑を閉じた後は、「処理を再開」またはEsc / Pで再開する。
- 画面右上から日本語・英語を切り替えられる。途中で切り替えてもランの進行は保持する。
- 言語・音量・ミュート・図鑑の発見記録はブラウザのローカルストレージに保存する。保存が利用できない環境でもプレイは可能。

## ランタイム図鑑

画面下の「ランタイム図鑑」に、遭遇した敵と取得した能力の情報を記録します。未発見項目は `???` と表示し、発見記録は次のランにも引き継ぎます。

## 音声

初期音量は100%です。保存済みの音量は引き継ぎます。BGM・効果音の共通音量とミュートを設定でき、設定画面では効果音を試聴できます。

- 戦闘中はオリジナルBGM「Runtime Loop」をループ再生する。
- 能力選択・一時停止・設定・図鑑・終了ではBGMを停止し、戦闘再開時は途中から再生する。新しいランは曲の先頭から始める。
- 起動・被弾・撃破・経験値回収・レベルアップ・能力取得・範囲攻撃・警告・終了に効果音を再生する。
